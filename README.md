# Gym Cycle Tracker v2

React Native + Expo + TypeScript.

## Запуск
```bash
npm install
npx expo start
```

## Новое в версии 2
- 4 шаблона: синергисты, фулбади, тяни/жми/ноги, антагонисты.
- Переключение шаблона и дней.
- Замена упражнения на альтернативу из списка похожих движений.
- Фильтры нагрузки на колени и локти.
- История, RIR, 1ПМ, прогрессия веса и локальное сохранение.
- Мягкая миграция журнала из ключа `gym-cycle-v1`.

Ограничения по суставам — это фильтр по типичным упражнениям, а не медицинская гарантия отсутствия нагрузки. При боли или травме программу нужно согласовать с врачом/физиотерапевтом.
